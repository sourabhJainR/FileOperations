# FileOperations

Privacy-first, browser-based file utility SPA. Files are processed locally in your browser; no server upload is required.

## Status
Initial prototype. Not production-ready: browser regression tests, accessibility, dependency security review, large-file/resource limits, and representative real-file validation are still pending.

See [app](apps/filekit/index.html) and [operation/fidelity/privacy notes](apps/filekit/README.md).

## Deployment
Static hosting (GitHub Pages compatible). CDN dependencies currently require network access. Do not use this prototype for sensitive files until the dependency and privacy controls are reviewed.

## Planned scope
PDF, images, spreadsheets, documents, archives, conversion, compare, resize, compact, merge/split, previews, batch processing, progress/cancel, accessibility, offline packaging and regression coverage.
